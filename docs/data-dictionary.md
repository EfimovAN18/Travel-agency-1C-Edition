# Словарь данных — ИС «Мечта путешественника»

Описаны все прикладные объекты конфигурации (целевая модель по ТЗ, части 1–3).
Схема связей — в [ERD.md](ERD.md).

**Обозначения**
- **Обяз.** — проверка заполнения (`ПроверкаЗаполнения = ВыдаватьОшибку`).
- Строка(N) — строка переменной длины N символов; Строка(N, фикс.) — фиксированной длины.
- Число(N, M) — N знаков всего, M после запятой; «неотр.» — только неотрицательные значения.
- Дата — квалификатор «Дата» (без времени); ДатаВремя — «Дата и время».
- Стандартные реквизиты (`Ссылка`, `ПометкаУдаления`, `Предопределенный`, `Проведен` и т. п.) не перечисляются, кроме `Код`, `Наименование`, `Номер`, `Дата`, у которых заданы параметры.

## 1. Выбор вида объекта

| Сущность | Вид | Почему |
|---|---|---|
| Организации, Сотрудники, Агенты, Клиенты, Страны, Города, Отели, Валюты | Справочник | Условно-постоянная информация, пополняется пользователями |
| Виды номеров | Справочник | Список пополняется пользователем и выведен в навигацию («Виды номеров гостиниц»), а перечисление в навигацию не выводится и в режиме «Предприятие» не редактируется |
| Роли сотрудников | Справочник с предопределёнными элементами | Используется как роль адресации задач бизнес-процесса |
| Пол, Статус клиента, Тип отеля | Перечисление | Фиксированный набор значений, задаётся в Конфигураторе |
| Города → Страны, Отели → Города | Подчинённые справочники (`Владелец`) | Город существует только в стране, отель — только в городе; отбор «города указанной страны» получается штатно |
| Паспортные данные | Реквизиты справочника «Клиенты» | Связь 1:1 с клиентом. Отдельный справочник не нужен (на форме это закладка карточки клиента) |
| Предварительное соглашение, Договор, Оплата, Ваучер | Документ | Хозяйственные события с датой и номером |
| Курсы валют | Регистр сведений (периодический, день) | Нужно значение курса **на дату** документа |
| Назначение сотрудника на роль | Регистр сведений «Регистр адресации» | Назначение выполняется в режиме «Предприятие» |
| Задолженность по договорам | Регистр накопления (остатки) | Отчёт «Неоплаченные договоры на дату» — остатки на дату |
| Продажи | Регистр накопления (обороты) | Отчёты «Динамика продаж» и «Эффективность» — обороты за период |
| Оформление поездки | Бизнес-процесс + задача | Этапы с исполнителями и напоминаниями (ТЗ, п. 3.1) |
| Название компании, путь к папке обмена | Константы | Одно значение на информационную базу |

### 5.3 Оплаты
Приём 100 % оплаты в рублях. Проводит только бухгалтер, и только из списка его задач. Частичная оплата запрещена.

| Реквизит | Синоним | Тип | Обяз. | Примечание |

| Клиент | Клиент | СправочникСсылка.Клиенты | да |
| СтранаПосещения | Страна | СправочникСсылка.Страны | да |
